# 💗 Страница для девушки

Готовая страница без сборщика и зависимостей.

## Как запустить

Просто открой `index.html` в браузере.

## Где менять текст

Открой `script.js`.

В самом верху находится:

```js
const config = {
  name: "Имя девушки",

  texts: {
    ...
  },

  colors: {
    ...
  }
};
```

Меняй только этот блок.

## Где менять цвета

В `config.colors`:

```js
primary: "#e85d7d",
background: "#fff7f9",
text: "#2b1720",
muted: "#80656d",
accent: "#ffd4df"
```

Можно вставлять любые HEX-цвета.

## Что есть

- адаптивный дизайн;
- интерактивное письмо;
- кнопка с сердечками;
- секретный сюрприз;
- анимации появления;
- анимированное сердце;
- переключение светлой/тёмной темы;
- сохранение выбранной темы в localStorage;
- все основные тексты в одном месте;
- основные цвета в одном месте;
- работает на телефоне и компьютере.

Музыки, галереи и счётчика отношений нет.
